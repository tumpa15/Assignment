# Assignment Repository

This repository contains my module-wise assignments completed as part of my learning journey in **Software Quality Assurance, Version Control, and AI-assisted development workflows**.

## 📚 Modules

### Module 1 — Introduction to AI-Driven Software Quality Assurance (SQA) 

This module covers the fundamental concepts of Software Quality Assurance and Software Testing, including:

Introduction to SQA and the importance of software quality,
QA vs QC vs Software Testing,
The impact of AI on Software Testing,
Responsibilities of QA Engineer, Software Test Engineer, and AI Quality Engineer,
Career roadmap of a QA professional.

### Module 2 - Software Development Life Cycle (SDLC) in the Age of AI 

This module covers Software Development Life Cycle (SDLC) and the practical use of AI in software development and requirements analysis.

Topics Covered:
SDLC lifecycle and workflow,
Different phases of SDLC,
Creating user stories for an E-commerce application using AI,
Converting user stories into acceptance criteria,
Creating a Sprint Backlog with AI assistance,
Reviewing and manually improving AI-generated outputs.

### Module 3 - Software Testing Life Cycle (STLC) with AI 

This module covers the Software Testing Life Cycle (STLC) and the practical use of AI in software testing activities.

Topics Covered:
Creating a Test Plan for an Online Shopping Website,
Understanding the key activities and phases of STLC,
Preparing test checklists for application features,
Login validation checklist,
Registration validation checklist,
Checkout validation checklist,
Using AI to assist in test planning and checklist preparation.

### Module 4 - Introduction to Programming Language with AI (JavaScript + Node.js)

This module introduces JavaScript programming and Node.js, with practical coding exercises and AI-assisted learning.

Topics Covered:
JavaScript programming fundamentals,
Even or odd number checking,
Finding the largest of three numbers,
Reversing a string,
Counting vowels in a string,
Removing duplicate values from an array,
Introduction to Node.js and how it works,

This module focuses on JavaScript programming practice and problem-solving through basic coding exercises.
